# Trend Analyzer

Analizador de tendencias basado en datos de Google Trends.

## Features

- ANALISIS de tendencias de búsqueda
- visualización interactiva
- predicción de popularidad con Prophet

## Tecnologías

- Python
- Streamlit
- Pandas
- Plotly
- Prophet

## Ejecutar el proyecto

Instalar dependencias

pip install -r requirements.txt

Ejecutar app

streamlit run app.py
